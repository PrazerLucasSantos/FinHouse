# FinHouse

Sistema de controle financeiro pessoal e doméstico **Casa a Dois / FinHouse**.

## Projeto

O aplicativo é executado pelo `index.html` e mantém os dados localmente no navegador usando armazenamento local.

Principais módulos: despesas, casa e salários, receitas, projeções, gráficos, reservas, investimentos, supermercado e consumos, veículos, contas e cartões, planejado x realizado e histórico.

## Execução

Sirva o repositório por HTTP (GitHub Pages, Live Server ou servidor local) e abra `index.html`.

A versão publicada neste commit corresponde à versão mais recente trabalhada no ChatGPT em 05/09/2026.
